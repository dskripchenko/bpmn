# Редактор

В пакете два слоя редактирования: `BpmnDocument` — ядро без фреймворка со
всеми операциями и отменой, и `BpmnEditor` — компонент Vue поверх него. Оба
правят XML на месте: чего они не знают — атрибуты исполнения, расширения
поставщиков, другие диаграммы файла, — записывается обратно без изменений.

## Редактор на Vue

```sh
npm install @dskripchenko/bpmn vue @dskripchenko/ui
```

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { BpmnEditor } from '@dskripchenko/bpmn/vue'
import '@dskripchenko/bpmn/style.css'

const xml = ref<string | null>(null) // null — новая диаграмма с одним начальным событием
</script>

<template>
  <BpmnEditor v-model="xml" style="height: 600px" />
</template>
```

Что может человек:

- **Создавать** — выбрать символ в палитре слева и щёлкнуть по холсту.
  Промежуточное событие, брошенное на границу действия, становится граничным.
  В совместной работе (collaboration) элементы попадают в пул и дорожку под
  указателем.
- **Продолжать схему** — контекстная панель рядом с выбранным элементом
  добавляет задачу, шлюз, промежуточное или конечное событие, сразу
  соединённые; соединяет с другим элементом; добавляет аннотацию; меняет тип;
  красит; удаляет. На пуле или дорожке — добавляет дорожку.
- **Выделять и двигать** — щелчок, Shift+щелчок или рамка по пустому холсту.
  Перетаскивание двигает выделенное: содержимое пула или развёрнутого
  подпроцесса едет вместе с ним, граничные события — вместе с действием,
  потоки прокладываются заново. Задача, брошенная в другую дорожку,
  подпроцесс или пул, переезжает туда и в файле.
- **Менять размер** — угловые маркеры у действий, подпроцессов, пулов,
  дорожек, групп и аннотаций.
- **Называть** — двойной щелчок (или F2) и ввод текста; Enter сохраняет,
  Shift+Enter переносит строку, Escape отменяет.
- **Свойства** — панель справа: идентификатор, название, тип, определение
  события, прерывающее или нет, повторение, условие и поток по умолчанию,
  описание.
- **Клавиатура** — Delete, Ctrl+Z / Ctrl+Shift+Z (Ctrl+Y), Ctrl+A, стрелки
  для сдвига (с Shift — на 10 px), Escape.
- **Холст** — прокрутка двигает, Ctrl+прокрутка масштабирует, Пробел+
  перетаскивание или средняя кнопка — тоже двигают; масштаб и «показать всё»
  — справа внизу.
- **Скачивание** — файл `.bpmn` или картинка `.svg`.

### Свойства и события

| Свойство     | Тип                  | По умолчанию | Значение                                      |
| ------------ | -------------------- | ------------ | --------------------------------------------- |
| `modelValue` | `string \| null`     | `null`       | XML файла (`v-model`); пусто — новая диаграмма |
| `readonly`   | `boolean`            | `false`      | Просмотр: сдвиг, масштаб, щелчки              |
| `properties` | `boolean`            | `false`      | Сразу показать панель свойств                 |
| `diagram`    | `string \| number`   | первая       | Какая диаграмма файла                         |
| `highlight`  | `string[]`           | `[]`         | Элементы, которые обвести                     |
| `locale`     | `string`             | страницы     | `ru…` — русский, иначе английский             |
| `labels`     | `Partial<BpmnLabels>`| —            | Замена текстов интерфейса                     |

| Событие             | Данные     | Когда                                                     |
| ------------------- | ---------- | --------------------------------------------------------- |
| `update:modelValue` | `string`   | После каждого изменения, отмены и повтора                 |
| `change`            | `string`   | То же                                                     |
| `select`            | `string[]` | Изменилось выделение                                      |
| `elementClick`      | `string`   | Щелчок по элементу                                        |
| `error`             | `Error`    | Операция, которую нотация не допускает, или нечитаемый файл |

Компонент отдаёт наружу `document` (`BpmnDocument`), `fit()`, `undo()`,
`redo()`, `toSvg()` и `selection`.

`BpmnView` — вариант только для просмотра: `<BpmnView :xml="xml" :highlight="['Task_1']" @element-click="…" />`.

Редактор следует теме `@dskripchenko/ui` на странице — светлой или тёмной;
переменные самого рисунка (см. [оформление](theming.md)) тоже можно задать.

## Ядро редактирования

`BpmnDocument` работает где угодно — в Node, в воркере, за другим интерфейсом:

```ts
import { BpmnDocument } from '@dskripchenko/bpmn'

const doc = new BpmnDocument() // или new BpmnDocument(xml)
const task = doc.createShape('userTask', { x: 300, y: 120 }, { name: 'Проверить заказ' })
doc.connect('StartEvent_1', task)
doc.undo()
doc.redo()
save(doc.xml)
```

Каждая операция — один шаг истории; она либо выполняется целиком, либо
оставляет файл как был. Запрещённая операция бросает `BpmnError`.

| Операция                                    | Что делает                                                            |
| ------------------------------------------- | --------------------------------------------------------------------- |
| `createShape(type, centre, options?)`       | Добавляет фигуру; `options`: `name`, `eventDefinition`, `attachTo` (граничное событие), `expanded`, `size`. Пул на диаграмме процесса оборачивает процесс |
| `addLane(pool, name?)`                      | Добавляет дорожку; первый вызов делит пул на две                      |
| `connect(source, target)`                   | Добавляет поток, который допускает нотация: управления, сообщений, ассоциацию, связь с данными |
| `canConnect(source, target)`                | Тип такого потока или `null`                                          |
| `move(ids, dx, dy)`                         | Двигает фигуры с содержимым; потоки следуют; контейнеры меняются при переносе |
| `resize(id, bounds)`                        | Меняет размер; пул и его дорожки подстраиваются друг под друга        |
| `remove(ids)`                               | Удаляет с содержимым, граничными событиями, потоками и ссылками       |
| `rename(id, text)`                          | Название, текст аннотации или категория группы                        |
| `setType(id, type)`                         | В пределах семейства: задача → пользовательская, шлюз → параллельный, начало → конец |
| `setEventDefinition(id, kind?)`             | `message`, `timer`, `error`, … или ничего                             |
| `setLoop(id, loop)`                         | `none`, `standard`, `parallel`, `sequential`                          |
| `setCondition(flow, text)`                  | Условие потока управления                                             |
| `setDefaultFlow(flow, isDefault?)`          | Поток по умолчанию у шлюза или действия                               |
| `setDocumentation(id, text)`                | Описание                                                              |
| `setAttribute(id, name, value?)`            | Любой простой атрибут (`isExecutable`, `cancelActivity`, …)           |
| `setId(id, next)`                           | Переименовывает id вместе со всеми ссылками на него                   |
| `setColors(ids, { fill?, stroke? })`        | Цвета — так, как их хранят bpmn.io и расширение OMG                   |
| `setWaypoints(flow, points)`                | Изломы потока                                                         |
| `setLabelBounds(id, bounds)`                | Где стоит внешняя подпись                                             |

Чтение: `model`, `diagram`, `xml`, `element(id)`, `shape(id)`, `ends(flow)`,
`processOf(id)`, `containerAt(point)`, `canUndo`, `canRedo`,
`onChange(listener)`, `load(xml)`. Новые id строятся как у моделеров
(`Activity_0b1x2yz`, `Flow_…`).

Для собственного интерфейса `hitTest`, `elementsIn`, `borderOf` и функции
видового окна (`zoomAt`, `fitView`, `toWorld`) отвечают на геометрические
вопросы, которые задаёт редактор.
